# WinLauncher

仿 Win7 / Win8 / Win10 / Win11 动态磁贴的独立开始菜单工具。

## ✨ 核心功能 (2.0 版本)

- **四模无缝切换**：完美支持 Win10（分栏磁贴）、Win8（全屏 Metro）、Win7（经典 Aero 玻璃）、Win11（极简单窗格）四种独立界面。
- **原生亚克力特效**：通过 Windows API 深度调用，实现真实的毛玻璃/液态玻璃背景，深浅色模式下均带有极佳的高级透明质感。
- **动态磁贴系统**：完美复刻 Win10 磁贴体验（拖拽换位、拖拽新建分组、自动填补空隙、右键调整尺寸及自定义颜色）。
- **智能拼音索引**：左侧应用列表不仅支持英文字母，还通过底层 API 支持中文拼音首字母自动分组与 A-Z 快速跳转。
- **深度皮肤系统**：支持导入 JSON 格式的皮肤文件，可深度定制各模式下的颜色、圆角、按钮等细节，并支持一键删除。
- **配置高可用**：支持配置的自动保存、手动导出备份（JSON）、以及一键还原（清空配置）。
- **快捷呼出与启动**：自动扫描系统开始菜单快捷方式，提取无箭头高清图标；失效应用点击时会自动提示清理。

## 🛠️ 技术栈与运行环境

- **开发框架**：WPF (.NET Framework 4.8)
- **开发工具**：Visual Studio 2022
- **运行环境**：Windows 7 SP1 / Windows 8 / Windows 10 / Windows 11 (Win7 需手动安装 .NET Framework 4.8 运行库)

## 🚀 如何编译和运行

1. 克隆仓库或下载源码。
2. 使用 Visual Studio 打开 `WinLauncher.sln` 解决方案。
3. 还原 NuGet 包并重新生成解决方案。
4. 按 `F5` 即可运行。

## 📦 打包发布

本项目使用 **Inno Setup** 进行安装包制作。
建议在 VS 中切换到 `Release` 模式编译，清理掉 `.pdb` 等调试文件后，将 `bin\Release` 目录下的文件作为 Inno Setup 的应用程序文件进行打包。
