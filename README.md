# WinLauncher

仿 Win10/Win8 动态磁贴的独立开始菜单工具。

## ✨ 核心功能

- **高度还原**：完美复刻 Win10/Win8 的动态磁贴（拖动换位、拖拽新建分组、自动填补空隙、右键调整大小）。
- **双模式切换**：支持 Win10 经典分栏模式与 Win8 全屏 Metro 模式。
- **快捷呼出**：自动扫描系统开始菜单（Start Menu）中的快捷方式，并提取无箭头高清图标。
- **A-Z 索引**：左侧应用列表支持按首字母自动分组，点击字母快速跳转。
- **个性定制**：支持深色/浅色主题一键切换，Win8 模式下可自定义背景颜色。
- **智能管理**：失效应用（被卸载）点击时会自动提示清理，空分组自动解散。
- **配置持久化**：自动保存磁贴布局、颜色、主题等配置到本地 `config.json`，重启不丢失。

## 🛠️ 技术栈与运行环境

- **开发框架**：WPF (.NET Framework 4.8)
- **开发工具**：Visual Studio 2022
- **运行环境**：Windows 10 / Windows 11（系统自带 .NET Framework 4.8）

## 🚀 如何编译和运行

1. 克隆仓库或下载源码。
2. 使用 Visual Studio 打开 `WinLauncher.sln` 解决方案。
3. 还原 NuGet 包并重新生成解决方案。
4. 按 `F5` 即可运行。

## 📦 打包发布

本项目使用 **Inno Setup** 进行安装包制作。
如果需要自己打包，请在 VS 中切换到 `Release` 模式编译，然后将 `bin\Release` 目录下的所有文件作为 Inno Setup 的应用程序文件进行打包。
